# SmartKisan - Rice Disease Detection

A Python-based desktop application for detecting rice leaf
diseases using deep learning.

## Features
- Upload a rice leaf image
- Predict rice leaf disease
- Display prediction confidence
- Show basic treatment advice
- Tkinter-based desktop interface

## Technologies
- Python
- TensorFlow / Keras
- OpenCV
- Tkinter
- NumPy
- Pillow

## Supported Classes
- Bacterial Leaf Blight
- Brown Spot
- Healthy
- Leaf Blast
- Leaf Scald
- Narrow Brown Spot

## Setup

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

## Note
Prediction results are model estimates and should be
verified by agricultural experts before treatment.
